# UserActivityProgress Model

Tracks user progress on activity-based incentive tasks and document submissions.

## Entity: UserActivityProgress

| Field                | Type     | Required | Constraints   | Notes                         |
| -------------------- | -------- | -------- | ------------- | ----------------------------- |
| id                   | UUID     | yes      | primary key   | Generated by database         |
| clientId             | UUID     | yes      | foreign key   | References Client (tenant)    |
| userId               | UUID     | yes      | foreign key   | References User               |
| activityDefinitionId | UUID     | yes      | foreign key   | References ActivityDefinition |
| incentiveId          | UUID     | yes      | foreign key   | References Incentive          |
| completed            | boolean  | yes      | default false | Whether activity is completed |
| completedAt          | datetime | no       | —             | When completed                |
| createdAt            | datetime | yes      | —             | ISO 8601                      |
| updatedAt            | datetime | yes      | —             | ISO 8601                      |

## Entity: UserActivityDocumentSubmission

| Field                 | Type                     | Required | Constraints | Notes                                  |
| --------------------- | ------------------------ | -------- | ----------- | -------------------------------------- |
| id                    | UUID                     | yes      | primary key | Generated by database                  |
| clientId              | UUID                     | yes      | foreign key | References Client (tenant)             |
| userId                | UUID                     | yes      | foreign key | References User                        |
| documentRequirementId | UUID                     | yes      | foreign key | References ActivityDocumentRequirement |
| activityDefinitionId  | UUID                     | yes      | foreign key | References ActivityDefinition          |
| fileName              | string                   | yes      | max 500     | Uploaded file name                     |
| filePath              | string                   | yes      | max 1000    | Storage path                           |
| fileSize              | long                     | no       | —           | File size in bytes                     |
| status                | DocumentSubmissionStatus | yes      | enum        | PENDING, APPROVED, REJECTED            |
| reviewedBy            | UUID                     | no       | —           | User who reviewed                      |
| reviewedAt            | datetime                 | no       | —           | When reviewed                          |
| rejectionReason       | string                   | no       | max 2000    | Reason if rejected                     |
| createdAt             | datetime                 | yes      | —           | ISO 8601                               |
| updatedAt             | datetime                 | yes      | —           | ISO 8601                               |

## Multi-Tenancy

- Both entities are tenant-scoped via `client_id`
