# SubProcessor Model

Represents a third-party sub-processor in the GDPR sub-processor registry.

| Field         | Type      | Required | Constraints | Notes                                             |
| ------------- | --------- | -------- | ----------- | ------------------------------------------------- |
| id            | UUID      | yes      | primary key | Generated by database                             |
| name          | string    | yes      | max 255     | Company name of the sub-processor                 |
| purpose       | string    | yes      | max 500     | Description of the processing purpose             |
| dataProcessed | string    | yes      | max 500     | Categories of personal data processed             |
| location      | string    | yes      | max 100     | Country where data is processed                   |
| dpaStatus     | DpaStatus | yes      | enum        | PENDING, SIGNED, EXPIRED                          |
| sccStatus     | SccStatus | yes      | enum        | NOT_REQUIRED, REQUIRED, SIGNED, DEPENDS_ON_REGION |
| addedAt       | datetime  | yes      | ISO 8601    | When the sub-processor was added                  |
| updatedAt     | datetime  | yes      | ISO 8601    | Last modification                                 |

## Notes

- Sub-processors are managed platform-wide by TENX_ADMIN
- CLIENT_ADMIN users can view the registry to fulfill transparency obligations
- Changes to the sub-processor registry should trigger notification to affected clients
