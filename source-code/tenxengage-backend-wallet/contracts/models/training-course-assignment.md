# TrainingCourseAssignment Model

Links an LMS course to a training incentive.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| incentiveId | UUID | yes | foreign key | References Incentive |
| courseId | string | yes | max 255 | External LMS course identifier |
| courseName | string | yes | max 255 | Course name (denormalized for display) |
| courseCategory | string | no | max 255 | Course category |
| courseProvider | string | no | max 255 | Course provider |
| courseDuration | string | no | max 50 | Duration (e.g. "2 hours") |
| courseLevel | CourseLevel | no | enum | BEGINNER, INTERMEDIATE, ADVANCED |
| required | boolean | yes | default true | Whether completion is mandatory |
| sortOrder | integer | yes | — | Display order |
| createdAt | datetime | yes | — | Set on creation |

## Relationships

- Belongs to one Incentive
