# AuditLog Model

Immutable audit trail for tracking all significant actions in the system.

| Field        | Type              | Required | Constraints | Notes                                        |
| ------------ | ----------------- | -------- | ----------- | -------------------------------------------- |
| id           | UUID              | yes      | primary key | Generated by database                        |
| clientId     | UUID              | yes      | foreign key | References Client (tenant)                   |
| actorType    | AuditActorType    | yes      | enum        | USER or SYSTEM                               |
| actorId      | UUID              | no       | —           | User ID (null for SYSTEM actions)            |
| actorEmail   | string            | no       | —           | Actor's email for display                    |
| actorName    | string            | no       | —           | Actor's name for display                     |
| userType     | string            | no       | —           | Role type of the actor (e.g. "CLIENT_ADMIN") |
| companyName  | string            | no       | —           | Actor's company name                         |
| action       | AuditAction       | yes      | enum        | See enums.md                                 |
| resourceType | AuditResourceType | yes      | enum        | See enums.md                                 |
| resourceId   | UUID              | no       | —           | ID of the affected resource                  |
| resourceName | string            | no       | —           | Name of the affected resource for display    |
| description  | string            | no       | max 2000    | Human-readable description of the action     |
| ipAddress    | string            | no       | max 45      | Client IP address                            |
| requestId    | UUID              | no       | —           | Request correlation ID                       |
| metadata     | jsonb             | no       | —           | Additional structured data about the action  |
| createdAt    | datetime          | yes      | —           | ISO 8601, immutable                          |

## Notes

- Audit logs are immutable — they cannot be edited or deleted
- Retention is governed by the RetentionPolicy for AUDIT_LOGS data category
- Logs are created automatically via `@Audited` annotation on controller methods
- Filterable by userType, action, search term, and date range
