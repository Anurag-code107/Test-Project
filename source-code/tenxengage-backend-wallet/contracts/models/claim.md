# Claim Model

Represents the claim lifecycle for purchase orders. Sellers can claim eligible deals to earn rewards.

## Entity: ClaimAction

Each record represents one user claiming one purchase order.

| Field           | Type     | Required | Constraints | Notes                       |
| --------------- | -------- | -------- | ----------- | --------------------------- |
| id              | UUID     | yes      | primary key | Generated by database       |
| clientId        | UUID     | yes      | foreign key | References Client (tenant)  |
| purchaseOrderId | UUID     | yes      | foreign key | References PurchaseOrder    |
| userId          | UUID     | yes      | foreign key | References User who claimed |
| claimedAt       | datetime | yes      | —           | When the user claimed       |
| createdAt       | datetime | yes      | —           | Set on creation             |
| updatedAt       | datetime | yes      | —           | Updated on modification     |

## Relationships

- ClaimAction belongs to PurchaseOrder (many-to-one)
- ClaimAction belongs to User (many-to-one)

## Business Rules

1. Multiple users can claim the same deal (up to `maxClaimersPerDeal` from the Incentive)
2. A user cannot claim the same deal twice
3. Claiming creates RewardTransactions for each eligible incentive's payout configs
4. Budget utilization is tracked per incentive per currency and enforced at claim time
5. Unclaiming reverses all RewardTransactions and debits RewardBalances
6. Users with `action.claim.unclaim` permission can unclaim deals

## Currency Types

Monetary currencies (included in monetary totals): `cash`, `points` (CurrencyType = MONETARY)
Non-monetary currencies (tracked separately): `tickets`, `credits` (CurrencyType = NON_MONETARY)

## API Response Shapes

### ClaimResponse (list view)

Returned by `GET /api/v1/claims`. Each row represents a purchase order with its claim status.

### ClaimDetailResponse (detail view)

Returned by `GET /api/v1/claims/{id}`. Includes:

- Purchase order details (orderNumber, orderDate, totalAmount, partner info)
- List of eligible incentives with reward breakdowns
- List of ineligible incentives with reasons
- List of claimers (users who have claimed this deal)
- Per-currency reward summaries

### ClaimSummaryResponse

Returned by `GET /api/v1/claims/summary`. Aggregate totals:

- totalEarnings per currency
- claimed/unclaimed counts
- filtered by status, date range
