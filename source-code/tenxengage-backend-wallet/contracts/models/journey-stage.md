# JourneyStage Model

A stage within a journey (multistage) incentive, linking to another incentive.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| incentiveId | UUID | yes | foreign key | References the parent Journey Incentive |
| linkedIncentiveId | UUID | yes | foreign key | References the Incentive used as this stage |
| sortOrder | integer | yes | — | Stage order (1-based) |
| createdAt | datetime | yes | — | Set on creation |

## Relationships

- Belongs to one Incentive (parent journey)
- References one Incentive (linked stage incentive)

## Notes

- A journey incentive has a `journeySequential` flag on the parent Incentive that determines if stages must be completed in order
- The linked incentive must be of type SALES, TRAINING, or ACTIVITY (not JOURNEY)
