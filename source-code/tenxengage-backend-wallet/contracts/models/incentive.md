# Incentive Model

Represents an incentive program created by a client admin to drive partner engagement.

## Entity Fields

| Field                   | Type                | Required | Constraints         | Notes                                                 |
| ----------------------- | ------------------- | -------- | ------------------- | ----------------------------------------------------- |
| id                      | UUID                | yes      | primary key         | Generated by database                                 |
| name                    | string              | yes      | max 255             | Display name of the incentive                         |
| description             | string              | no       | max 2000            | Detailed description                                  |
| incentiveType           | IncentiveType       | yes      | enum                | SALES, TRAINING, ACTIVITY, JOURNEY                    |
| status                  | IncentiveStatus     | yes      | enum, default DRAFT | See enums.md                                          |
| clientId                | UUID                | yes      | foreign key         | References Client (tenant)                            |
| createdBy               | UUID                | yes      | foreign key         | References User who created it                        |
| startDate               | datetime            | no       | ISO 8601            | Program start date                                    |
| endDate                 | datetime            | no       | ISO 8601            | Program end date                                      |
| timezone                | string              | no       | max 50              | IANA timezone (e.g. "America/New_York")               |
| deleted                 | boolean             | yes      | default false       | Soft delete flag                                      |
| journeySequential       | boolean             | yes      | default true        | Whether journey stages must be completed in order     |
| rewardCurrencies        | string              | no       | JSON                | JSON array of currency IDs (e.g. `["cash","points"]`) |
| rewardMessage           | string              | no       | max 500             | Message shown to partners                             |
| rewardAmounts           | string              | no       | JSON, TEXT          | JSON map of currency amounts                          |
| fiscalYears             | string              | no       | JSON                | JSON array of fiscal years                            |
| fiscalQuarters          | string              | no       | JSON                | JSON array of fiscal quarters                         |
| trainingRequiredCount   | integer             | no       | —                   | Minimum training courses required                     |
| countriesText           | string              | no       | TEXT                | Free-text country targeting                           |
| specificPartners        | string              | no       | TEXT                | Free-text partner targeting                           |
| maxPerPartner           | decimal             | no       | precision 15,2      | Max reward per partner company                        |
| maxPerUser              | decimal             | no       | precision 15,2      | Max reward per user                                   |
| maxClaimersPerDeal      | integer             | no       | default 1           | Max users who can claim a single deal                 |
| businessObjective       | string              | no       | TEXT                | Business objective description                        |
| complianceRiskLevel     | ComplianceRiskLevel | no       | enum                | Compliance risk assessment                            |
| complianceApprovedAt    | datetime            | no       | —                   | When compliance approved                              |
| complianceApprovedBy    | UUID                | no       | —                   | Who approved compliance                               |
| maxPerPartnerByCurrency | string              | no       | TEXT                | JSON map of per-partner caps by currency              |
| maxPerUserByCurrency    | string              | no       | TEXT                | JSON map of per-user caps by currency                 |
| customFieldValues       | jsonb               | no       | —                   | Values for custom builder fields                      |
| requiresApproval        | boolean             | no       | —                   | Whether incentive requires approval workflow          |
| requiredApprovals       | integer             | no       | —                   | Number of approvals required                          |
| approvalRound           | integer             | no       | default 1           | Current approval round                                |
| statusChangedAt         | datetime            | no       | —                   | When status last changed                              |
| createdAt               | datetime            | yes      | —                   | Set on creation                                       |
| updatedAt               | datetime            | yes      | —                   | Updated on modification                               |

## Relationships

- Has one IncentiveBudget (one-to-one, cascade ALL, orphan removal)
- Has many IncentiveAudienceRule (one-to-many, cascade ALL, orphan removal)
- Has many SalesRequirement (one-to-many, cascade ALL, orphan removal; only when type = SALES)
- Has many TrainingCourseAssignment (one-to-many, cascade ALL, orphan removal; only when type = TRAINING)
- Has many ActivityDefinition (one-to-many, cascade ALL, orphan removal; only when type = ACTIVITY)
- Has many JourneyStage (one-to-many, cascade ALL, orphan removal; only when type = JOURNEY)
- Has many IncentiveDocument (one-to-many, cascade ALL, orphan removal)
- Has many IncentiveApprover (one-to-many, cascade ALL, orphan removal)
- Belongs to one Client (tenant)
- Belongs to one User (createdBy)

## Multi-Tenancy

- All queries filter by `clientId` (tenant isolation)
- Uses Hibernate `@Filter(name = "tenantFilter")` for automatic scoping

## Soft Delete

- The `deleted` field is a boolean flag; queries must filter `deleted = false`
- Deleting an incentive sets `deleted = true` (not a hard delete)
