# IncentiveAudienceRule Model

Defines audience targeting rules for an incentive (regions, partner types, roles, countries).

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| incentiveId | UUID | yes | foreign key | References Incentive |
| ruleType | AudienceRuleType | yes | enum | REGION, PARTNER_TYPE, ROLE, COUNTRY |
| ruleValue | string | yes | max 255 | The value (e.g. "USA", "Reseller", "Partner Seller") |
| createdAt | datetime | yes | — | Set on creation |

## Relationships

- Belongs to one Incentive
