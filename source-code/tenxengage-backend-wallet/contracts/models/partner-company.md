# PartnerCompany Model

Represents a partner company that participates in a client's incentive programs. Partner companies contain partner admins and sellers.

| Field                         | Type                          | Required | Constraints  | Notes                                     |
| ----------------------------- | ----------------------------- | -------- | ------------ | ----------------------------------------- |
| id                            | UUID                          | yes      | primary key  | Generated by database                     |
| name                          | string                        | yes      | max 255      | Display name of the partner company       |
| externalPartnerId             | string                        | no       | max 100      | ID from external system (e.g., CRM)       |
| clientId                      | UUID                          | yes      | foreign key  | References Client (tenant)                |
| status                        | PartnerCompanyStatus          | yes      | enum         | See enums.md                              |
| website                       | string                        | no       | URL, max 500 | Company website                           |
| contactPhone                  | string                        | no       | max 20       | Primary contact phone                     |
| metadata                      | jsonb                         | no       | default {}   | Flexible key-value metadata               |
| antiBriberyAcknowledgedAt     | datetime                      | no       | —            | When anti-bribery policy was acknowledged |
| antiBriberyPolicyVersion      | string                        | no       | max 20       | Version of acknowledged policy            |
| governmentDealRestrictionMode | GovernmentDealRestrictionMode | no       | enum         | Override for government deal handling     |
| createdAt                     | datetime                      | yes      | —            | ISO 8601, set on creation                 |
| updatedAt                     | datetime                      | yes      | —            | ISO 8601, updated on modification         |

## Relationships

- Belongs to one Client (tenant)
- Has many Users (one-to-many via `users.partner_company_id`)
- Has many PartnerCompanyLocations (one-to-many — location assignments)

## Constraints

- Unique constraint: `(client_id, name)` — no two partner companies with the same name within a client

## API Response Fields

When returned in API responses, include all fields plus:

- `clientName` as a string (convenience field)

## Notes

- This entity is tenant-scoped — all queries filter by `client_id`.
- Users with `action.partner_company.create/edit/delete` permissions can manage partner companies.
