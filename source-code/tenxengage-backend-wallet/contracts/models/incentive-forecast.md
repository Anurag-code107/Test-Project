# IncentiveForecast Model

AI-generated forecast for an incentive program. Uses a hybrid architecture:
statistical pre-aggregation layer feeds compact data summaries to the Claude API
for intelligent analysis, prediction adjustment, and natural-language insight generation.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| incentiveId | UUID | yes | foreign key | References Incentive |
| estimatedRoi | string | yes | decimal string | Estimated return on investment percentage (e.g. "215.50") |
| estimatedParticipation | integer | yes | >= 0 | Estimated number of participating partners |
| estimatedParticipationRate | string | yes | decimal string 0-100 | Participation rate as percentage (e.g. "37.40") |
| estimatedTotalCost | string | yes | decimal string | Estimated total program cost |
| estimatedRevenue | string | yes | decimal string | Estimated revenue generated |
| estimatedNetNewDeals | integer | no | >= 0 | Predicted net new deal count above baseline |
| estimatedNetNewBookings | string | no | decimal string | Predicted net new bookings revenue above baseline |
| confidenceScore | string | yes | decimal string 0-95 | AI confidence score (higher = more historical data available) |
| dataQualityScore | string | no | decimal string 0-100 | How much historical data was available for the prediction |
| modelVersion | string | no | max 20 chars | Algorithm version (e.g. "v1-claude", "statistical-fallback") |
| regionalBreakdown | jsonb | no | JSON array | Per-region predictions (see RegionBreakdown below) |
| monthlyProjections | jsonb | no | JSON array | Array of { month, revenue, cost, participants } |
| similarIncentiveIds | jsonb | no | JSON array | UUIDs of historical incentives that informed the prediction |
| aiInsights | text | no | JSON string | Claude-generated insights serialized as JSON (see AiInsight below) |
| generatedAt | datetime | yes | — | When the forecast was generated |
| createdAt | datetime | yes | — | Set on creation |

## Nested Types

### RegionBreakdown

| Field | Type | Notes |
|-------|------|-------|
| region | string | Region name (AMERICAS, LATAM, APJ, EMEAR) |
| budgetUtilizedPct | string | Predicted budget utilization percentage for this region |
| netNewDeals | integer | Predicted net new deals for this region |
| netNewBookings | string | Predicted net new bookings revenue for this region |
| roi | string | Predicted ROI for this region |
| participationRate | string | Predicted participation rate for this region |
| budgetAllocated | string | Budget allocated to this region |
| budgetPredictedSpend | string | Predicted spend for this region |

### AiInsight

| Field | Type | Notes |
|-------|------|-------|
| type | string | One of: strength, risk, opportunity, warning |
| title | string | Short title (max 60 chars) |
| detail | string | 1-2 sentence explanation |

## Relationships

- Belongs to one Incentive

## API Endpoints

| Method | Path | Returns | Notes |
|--------|------|---------|-------|
| POST | `/api/v1/incentives/{id}/forecast` | SSE stream | Generates forecast via Claude AI, streams progress events |
| GET | `/api/v1/incentives/{id}/forecast` | ForecastResponse | Returns most recent cached forecast (404 if none) |

### SSE Event Types (POST endpoint)

| Event | Data | Description |
|-------|------|-------------|
| status | `{ message: string }` | Progress updates (e.g. "Analyzing historical data...") |
| forecast | ForecastResponse | Final forecast result |
| done | `{ status: "complete" }` | Stream completion signal |
| error | `{ message: string }` | Error message if forecast fails |
