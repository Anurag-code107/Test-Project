# Currency Model

Represents a reward currency configured per tenant. Replaces the former global Currency enum with a flexible, tenant-scoped currency system.

| Field               | Type         | Required | Constraints        | Notes                                                          |
| ------------------- | ------------ | -------- | ------------------ | -------------------------------------------------------------- |
| id                  | UUID         | yes      | primary key        | Generated by database                                          |
| clientId            | UUID         | yes      | foreign key        | References Client (tenant)                                     |
| code                | string       | yes      | max 50             | Currency identifier (e.g. "cash", "points", "tickets")         |
| name                | string       | yes      | max 100            | Display name (e.g. "Cash Rewards")                             |
| type                | CurrencyType | yes      | enum               | MONETARY or NON_MONETARY                                       |
| conversionRate      | decimal      | yes      | precision 15,4     | Conversion rate to USD (e.g. 1.0 for cash, 0.005 for points)   |
| unit                | string       | no       | max 20, default "" | Display unit (e.g. "pts", "tickets")                           |
| isCurrencyFormatted | boolean      | yes      | default false      | Whether to display with currency symbol (e.g. $100 vs 100 pts) |
| isDefault           | boolean      | yes      | default false      | Whether this is the default currency for the tenant            |
| createdAt           | datetime     | yes      | —                  | ISO 8601                                                       |
| updatedAt           | datetime     | yes      | —                  | ISO 8601                                                       |

## Multi-Tenancy

- Tenant-scoped via `client_id`

## Default Currencies

Four currencies are seeded per client:

| code    | name    | type         | conversionRate | unit    |
| ------- | ------- | ------------ | -------------- | ------- |
| cash    | Cash    | MONETARY     | 1.0            |         |
| points  | Points  | MONETARY     | 0.005          | pts     |
| tickets | Tickets | NON_MONETARY | 0.0            | tickets |
| credits | Credits | NON_MONETARY | 0.0            | credits |

## Notes

- Monetary currencies (cash, points) contribute to compliance value cap calculations
- Non-monetary currencies have a conversionRate of 0 and are excluded from monetary totals
- The `code` field is used as `currencyId` throughout the system (in PayoutConfig, RewardTransaction, etc.)
