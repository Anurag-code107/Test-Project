# IncentiveBudget Model

Budget configuration for an incentive program.

## Entity Fields

| Field               | Type             | Required | Constraints          | Notes                                                     |
| ------------------- | ---------------- | -------- | -------------------- | --------------------------------------------------------- |
| id                  | UUID             | yes      | primary key          | Generated by database                                     |
| incentiveId         | UUID             | yes      | foreign key, unique  | References Incentive (one-to-one)                         |
| totalBudget         | decimal          | yes      | precision 15,2       | Total budget amount                                       |
| currencyId          | string           | yes      | max 50               | Currency identifier (e.g. "cash", "points")               |
| allocationMethod    | AllocationMethod | yes      | enum                 | EQUAL, WEIGHTED, PERFORMANCE_BASED                        |
| budgetMode          | BudgetMode       | yes      | enum, default GLOBAL | GLOBAL or PER_LOCATION                                    |
| budgetLocationLevel | UUID             | no       | foreign key          | References LocationLevel (when budgetMode = PER_LOCATION) |
| createdAt           | datetime         | yes      | —                    | Set on creation                                           |
| updatedAt           | datetime         | yes      | —                    | Updated on modification                                   |

## Relationships

- Belongs to one Incentive (unique foreign key)
- Belongs to one LocationLevel (optional, for location-based budgets)
- Has many LocationBudgetAllocation (one-to-many, cascade ALL)

## API Response Shape

### BudgetResponse (returned inside IncentiveDetailResponse)

| Field                 | Type                               | Notes          |
| --------------------- | ---------------------------------- | -------------- |
| totalBudget           | string                             | Decimal string |
| currencyId            | string                             |                |
| allocationMethod      | string                             | Enum name      |
| budgetMode            | string                             | Enum name      |
| budgetLocationLevelId | UUID                               | nullable       |
| locationAllocations   | LocationBudgetAllocationResponse[] | nullable       |

### BudgetInput (used in create/update requests)

| Field                 | Type                            | Required | Notes                                           |
| --------------------- | ------------------------------- | -------- | ----------------------------------------------- |
| totalBudget           | string                          | yes      | Decimal string                                  |
| currencyId            | string                          | yes      | max 50                                          |
| allocationMethod      | string                          | yes      | Enum: EQUAL, WEIGHTED, PERFORMANCE_BASED        |
| budgetMode            | string                          | no       | Enum: GLOBAL, PER_LOCATION (defaults to GLOBAL) |
| budgetLocationLevelId | UUID                            | no       | Required when budgetMode = PER_LOCATION         |
| locationAllocations   | LocationBudgetAllocationInput[] | no       | Per-location amounts                            |

**Note:** Budget utilization is tracked separately in the BudgetUtilization entity.
