# LocationBudgetAllocation Model

Per-LocationValue budget allocation under an IncentiveBudget. One row per `(budget, locationValue)` pair, where `locationValue` may be at any depth in the location hierarchy (Region, Country, State, City, ...).

When a budget is in `PER_LOCATION` mode, the user's eligibility scope can be narrowed to specific deeper-level LocationValues (e.g. a specific State within a Country within a Region). The allocation tree mirrors that hierarchy: parents must equal the sum of their children at every depth, with the client auto-filling residuals before save.

## Entity Fields

| Field           | Type    | Required | Constraints        | Notes                                                |
| --------------- | ------- | -------- | ------------------ | ---------------------------------------------------- |
| id              | UUID    | yes      | primary key        | Generated by database                                |
| budgetId        | UUID    | yes      | foreign key        | References IncentiveBudget                           |
| locationValueId | UUID    | yes      | foreign key        | References LocationValue at any depth                |
| amount          | decimal | yes      | precision 15,2     | Allocation amount in the budget's currency           |
| createdAt       | datetime| yes      | —                  | Set on creation                                      |
| updatedAt       | datetime| yes      | —                  | Updated on modification                              |

## Constraints

- `UNIQUE (budgetId, locationValueId)` — at most one allocation per (budget, location) pair.
- `locationValueId` has no depth restriction — any depth in the LocationValue hierarchy is valid.

## Relationships

- Belongs to one IncentiveBudget (cascade delete from parent)
- Belongs to one LocationValue

## API Shapes

### LocationAllocationInput (used inside BudgetInput.locationAllocations)

| Field           | Type   | Required | Notes                                  |
| --------------- | ------ | -------- | -------------------------------------- |
| locationValueId | UUID   | yes      | FK to LocationValue at any depth       |
| amount          | string | yes      | Decimal string (e.g. "12500.00")       |

### LocationAllocationResponse (used inside BudgetResponse.locationAllocations)

| Field             | Type   | Notes                                       |
| ----------------- | ------ | ------------------------------------------- |
| locationValueId   | UUID   |                                             |
| locationLevelId   | UUID   | The LocationLevel this value belongs to     |
| locationValueName | string | Display name (e.g. "California")            |
| levelName         | string | Display name of the level (e.g. "State")    |
| amount            | string | Decimal string                              |

The response shape is denormalized so the client can render the allocation tree without a separate hierarchy lookup.
