# PartnerKyc Model

Represents a Know Your Customer verification record for a partner company.

## Entity Fields

| Field                | Type      | Required | Constraints         | Notes                             |
| -------------------- | --------- | -------- | ------------------- | --------------------------------- |
| id                   | UUID      | yes      | primary key         | Generated by database             |
| clientId             | UUID      | yes      | foreign key         | References Client (tenant)        |
| partnerCompanyId     | UUID      | yes      | foreign key, unique | References PartnerCompany         |
| legalEntityName      | string    | no       | max 255             | Legal name of the entity          |
| registrationNumber   | string    | no       | max 100             | Business registration number      |
| incorporationCountry | string    | no       | max 10              | ISO country code of incorporation |
| taxId                | string    | no       | max 100             | Tax identification number         |
| kycStatus            | KycStatus | yes      | enum                | See enums.md                      |
| approvedBy           | UUID      | no       | —                   | User who approved                 |
| approvedAt           | datetime  | no       | ISO 8601            | When approved                     |
| expiresAt            | datetime  | no       | ISO 8601            | When KYC approval expires         |
| rejectionReason      | string    | no       | TEXT                | Reason for rejection              |
| createdAt            | datetime  | yes      | ISO 8601            | Set on creation                   |
| updatedAt            | datetime  | yes      | ISO 8601            | Updated on modification           |

## Related: PartnerBeneficialOwner

| id                  | UUID     | yes      | primary key   | Generated by database           |
| kycRecordId         | UUID     | yes      | foreign key   | References PartnerKycRecord     |
| fullName            | string   | yes      | max 255       |                                 |
| nationality         | string   | no       | max 10        | ISO country code                |
| ownershipPercentage | decimal  | no       | precision 5,2 | Percentage of ownership         |

| createdAt           | datetime | yes      | ISO 8601      |                                 |

## Relationships

- Belongs to one PartnerCompany (unique — one KYC record per partner)
- Has many PartnerBeneficialOwner

## Business Rules

- KYC approval expires after a configurable number of days (see risk-config endpoint)
- Expired KYC generates a KYC_EXPIRED compliance alert
- Only one active KYC record per partner company
- Status transitions: NOT_STARTED -> IN_PROGRESS -> APPROVED | REJECTED; APPROVED -> EXPIRED

## Multi-Tenancy

- Tenant-scoped via `client_id`
