# FiscalYearConfig Model

Defines fiscal year and quarter boundaries for a tenant. Used for incentive scheduling, reporting, and dashboard filtering.

| Field         | Type          | Required | Constraints | Notes                                                        |
| ------------- | ------------- | -------- | ----------- | ------------------------------------------------------------ |
| id            | UUID          | yes      | primary key | Generated by database                                        |
| clientId      | UUID          | yes      | foreign key | References Client (tenant)                                   |
| label         | string        | yes      | max 20      | Fiscal year label (e.g. "FY2025")                            |
| startDate     | date          | yes      | —           | Fiscal year start                                            |
| endDate       | date          | yes      | —           | Fiscal year end                                              |
| quarterMethod | QuarterMethod | yes      | enum        | MONTHS, WEEKS, DAYS, or CUSTOM                               |
| quarterSize   | integer       | no       | —           | Size of each quarter (months/weeks/days depending on method) |
| q1StartDate   | date          | no       | —           | Custom Q1 start (when quarterMethod = CUSTOM)                |
| q1EndDate     | date          | no       | —           | Custom Q1 end                                                |
| q2StartDate   | date          | no       | —           | Custom Q2 start                                              |
| q2EndDate     | date          | no       | —           | Custom Q2 end                                                |
| q3StartDate   | date          | no       | —           | Custom Q3 start                                              |
| q3EndDate     | date          | no       | —           | Custom Q3 end                                                |
| q4StartDate   | date          | no       | —           | Custom Q4 start                                              |
| q4EndDate     | date          | no       | —           | Custom Q4 end                                                |
| createdAt     | datetime      | yes      | —           | ISO 8601                                                     |
| updatedAt     | datetime      | yes      | —           | ISO 8601                                                     |

## Multi-Tenancy

- Tenant-scoped via `client_id`

## Notes

- Multiple fiscal years can be defined per client
- The `current` fiscal year is determined by which date range contains today's date
- Incentives reference fiscal years/quarters by label string
