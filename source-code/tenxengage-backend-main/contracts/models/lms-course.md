# LmsCourse Model

Represents an LMS (Learning Management System) course available for training incentives.

## Entity: LmsCourse

| Field            | Type     | Required | Constraints | Notes                               |
| ---------------- | -------- | -------- | ----------- | ----------------------------------- |
| id               | UUID     | yes      | primary key | Generated by database               |
| externalCourseId | string   | yes      | max 100     | ID from the external LMS system     |
| name             | string   | yes      | —           | Course name                         |
| description      | string   | no       | TEXT        | Course description                  |
| category         | string   | no       | max 100     | Course category                     |
| metadata         | jsonb    | no       | default {}  | Additional course metadata from LMS |
| createdAt        | datetime | yes      | —           | ISO 8601                            |
| updatedAt        | datetime | yes      | —           | ISO 8601                            |

## Entity: UserCourseCompletion

Tracks when a user completes an LMS course.

| Field       | Type     | Required | Constraints | Notes                                                   |
| ----------- | -------- | -------- | ----------- | ------------------------------------------------------- |
| id          | UUID     | yes      | primary key | Generated by database                                   |
| clientId    | UUID     | yes      | foreign key | References Client (tenant)                              |
| userId      | UUID     | yes      | foreign key | References User                                         |
| courseId    | UUID     | yes      | foreign key | References LmsCourse                                    |
| completedAt | datetime | yes      | —           | When the course was completed                           |
| source      | string   | no       | max 20      | How completion was recorded (e.g. "MANUAL", "LMS_SYNC") |
| metadata    | jsonb    | no       | default {}  | Additional completion data                              |
| createdAt   | datetime | yes      | —           | ISO 8601                                                |
| updatedAt   | datetime | yes      | —           | ISO 8601                                                |

## Notes

- LmsCourse is NOT tenant-scoped (shared catalog)
- UserCourseCompletion IS tenant-scoped via `client_id`
- Courses are linked to incentives via TrainingCourseAssignment
