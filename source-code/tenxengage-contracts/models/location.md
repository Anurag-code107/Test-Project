# Location Model

Hierarchical location system for organizing partners, budgets, and audience targeting.

## Entity: LocationLevel

Defines a level in the location hierarchy (e.g. Region > Country > State).

| Field        | Type     | Required | Constraints  | Notes                                             |
| ------------ | -------- | -------- | ------------ | ------------------------------------------------- |
| id           | UUID     | yes      | primary key  | Generated by database                             |
| clientId     | UUID     | yes      | foreign key  | References Client (tenant)                        |
| name         | string   | yes      | max 100      | Level name (e.g. "Region", "Country")             |
| depth        | integer  | yes      | —            | Hierarchy depth (0 = top level)                   |
| useInBuilder | boolean  | yes      | default true | Available in incentive builder audience targeting |
| useInFilters | boolean  | yes      | default true | Available in dashboard/report filters             |
| isRequired   | boolean  | yes      | default true | If true, field must be filled in participant eligibility step of incentive builder |
| createdAt    | datetime | yes      | —            | ISO 8601                                          |
| updatedAt    | datetime | yes      | —            | ISO 8601                                          |

## Entity: LocationValue

A specific value within a location level (e.g. "Americas" at the Region level).

| Field     | Type     | Required | Constraints | Notes                                                |
| --------- | -------- | -------- | ----------- | ---------------------------------------------------- |
| id        | UUID     | yes      | primary key | Generated by database                                |
| clientId  | UUID     | yes      | foreign key | References Client (tenant)                           |
| levelId   | UUID     | yes      | foreign key | References LocationLevel                             |
| parentId  | UUID     | no       | foreign key | References parent LocationValue (null for top level) |
| name      | string   | yes      | max 255     | Value name (e.g. "Americas")                         |
| code      | string   | no       | max 50      | Short code (e.g. "AMER")                             |
| createdAt | datetime | yes      | —           | ISO 8601                                             |
| updatedAt | datetime | yes      | —           | ISO 8601                                             |

## Relationships

- LocationLevel belongs to Client, has many LocationValue
- LocationValue belongs to LocationLevel and optionally to a parent LocationValue
- LocationValue has many children LocationValue (self-referential tree)
- LocationValue is referenced by: PartnerCompanyLocation, LocationBudgetAllocation, IncentiveAudienceRule

## Multi-Tenancy

- Both entities are tenant-scoped via `client_id`

## Notes

- The hierarchy is fully configurable per tenant (number of levels, names, values)
- `useInBuilder` and `useInFilters` control where each level appears in the UI
- `isRequired` gates the Participant Eligibility step of the incentive builder — if true, admin must fill out field. Defaults to true so new levels are mandatory by default.
- Partner companies are assigned to location values via PartnerCompanyLocation join table
