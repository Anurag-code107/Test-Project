# UserPermissionOverride Model

Per-user permission overrides (layer 5 of the permission hierarchy). Allows granting or revoking specific permissions for individual users.

| Field         | Type     | Required | Constraints  | Notes                                          |
| ------------- | -------- | -------- | ------------ | ---------------------------------------------- |
| id            | UUID     | yes      | primary key  | Generated by database                          |
| clientId      | UUID     | yes      | foreign key  | References Client (tenant)                     |
| userId        | UUID     | yes      | foreign key  | References User                                |
| permissionKey | string   | yes      | max 100      | Permission identifier                          |
| granted       | boolean  | yes      | default true | Whether this permission is granted to the user |
| createdAt     | datetime | yes      | —            | ISO 8601                                       |
| updatedAt     | datetime | yes      | —            | ISO 8601                                       |

## Notes

- User overrides are the most specific layer — they take final precedence
- Managed by users with `action.permissions.assign` permission
