# PoEligibilityMapping Model

Maps purchase orders to incentives with eligibility determination. Created by the tagging engine.

## Entity: PoEligibilityMapping

| Field               | Type     | Required | Constraints | Notes                                            |
| ------------------- | -------- | -------- | ----------- | ------------------------------------------------ |
| id                  | UUID     | yes      | primary key | Generated by database                            |
| clientId            | UUID     | yes      | foreign key | References Client (tenant)                       |
| taggingJobId        | UUID     | yes      | —           | References TaggingJob that created this mapping  |
| purchaseOrderId     | UUID     | yes      | foreign key | References PurchaseOrder                         |
| incentiveId         | UUID     | yes      | foreign key | References Incentive                             |
| eligible            | boolean  | yes      | —           | Whether the PO is eligible for this incentive    |
| ineligibilityReason | string   | no       | TEXT        | Why the PO is not eligible (if eligible = false) |
| createdAt           | datetime | yes      | —           | ISO 8601                                         |
| updatedAt           | datetime | yes      | —           | ISO 8601                                         |

## Entity: EligibilityPayout

Pre-calculated payout amounts for an eligible PO-incentive pair.

| Field                | Type     | Required | Constraints    | Notes                           |
| -------------------- | -------- | -------- | -------------- | ------------------------------- |
| id                   | UUID     | yes      | primary key    | Generated by database           |
| eligibilityMappingId | UUID     | yes      | foreign key    | References PoEligibilityMapping |
| requirementId        | UUID     | yes      | —              | References SalesRequirement     |
| currencyId           | string   | yes      | max 50         | Currency identifier             |
| payoutAmount         | decimal  | yes      | precision 15,2 | Calculated payout amount        |
| createdAt            | datetime | yes      | —              | ISO 8601                        |
| updatedAt            | datetime | yes      | —              | ISO 8601                        |

## Multi-Tenancy

- Tenant-scoped via `client_id` on PoEligibilityMapping

## Notes

- Mappings are regenerated each time the tagging job runs
- A PO is flagged `needsRetagging = true` when its data changes
- The claims page uses these mappings to show eligible/ineligible incentives per deal
