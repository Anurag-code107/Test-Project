# Acknowledgment Model

Represents an anti-bribery policy acknowledgment by a partner company for an incentive program.

## AcknowledgmentResponse

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| incentiveId | UUID | yes | foreign key | References Incentive |
| partnerCompanyId | UUID | yes | foreign key | References PartnerCompany |
| acknowledgedByUserId | UUID | yes | foreign key | References User (the PARTNER_ADMIN who acknowledged) |
| acknowledgedByName | string | yes | — | Display name of the acknowledging user |
| acknowledgedAt | datetime | yes | ISO 8601 | When the acknowledgment was recorded |
| policyVersion | string | yes | max 50 | Version of the anti-bribery policy acknowledged |

## AcknowledgeProgramRequest

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| incentiveId | UUID | yes | foreign key | Incentive program being acknowledged |
| partnerCompanyId | UUID | yes | foreign key | Partner company making the acknowledgment |
| policyVersion | string | yes | max 50 | Version of the policy being acknowledged |

## Relationships

- Belongs to one Incentive
- Belongs to one PartnerCompany
- Belongs to one User (acknowledgedBy)

## Business Rules

- Each partner company can only acknowledge a given incentive once (unique constraint on incentiveId + partnerCompanyId)
- Acknowledgment is required before partner sellers can participate in incentive programs
- Acknowledgments are immutable once recorded
