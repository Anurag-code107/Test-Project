# Connector Model

Represents an external data source connection configured by a Client Admin. Stores encrypted credentials for Salesforce, Microsoft Dynamics 365, Snowflake, or HubSpot.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| clientId | UUID | yes | foreign key | References Client (tenant) |
| connectorType | ConnectorType | yes | enum | See enums.md |
| name | string | yes | max 255 | Display name (e.g. "Production Salesforce") |
| status | ConnectorStatus | yes | enum, default DISCONNECTED | See enums.md |
| config | JSON (encrypted) | yes | — | Encrypted JSON containing credentials (varies by connector type) |
| authType | string | no | max 30 | Sub-auth type for connectors with multiple auth modes (e.g. Snowflake: LOGIN, PASSKEY, OAUTH) |
| lastSyncAt | datetime | no | — | Timestamp of last successful data sync |
| lastSyncStatus | string | no | max 50 | Human-readable sync status message |
| createdAt | datetime | yes | — | ISO 8601, set on creation |
| updatedAt | datetime | yes | — | ISO 8601, updated on modification |

## Config Shapes by Connector Type

### Salesforce
```json
{ "clientId": "...", "clientSecret": "...", "baseUrl": "https://login.salesforce.com" }
```

### Microsoft Dynamics 365
```json
{ "clientId": "...", "clientSecret": "...", "oauthAuthority": "https://login.microsoftonline.com/{tenantId}", "resource": "https://org.crm.dynamics.com" }
```

### Snowflake (authType = LOGIN)
```json
{ "username": "...", "password": "...", "url": "https://account.snowflakecomputing.com", "role": "ACCOUNTADMIN" }
```

### Snowflake (authType = PASSKEY)
```json
{ "username": "...", "password": "...", "privateKey": "...", "privateKeyPassword": "...", "url": "..." }
```

### Snowflake (authType = OAUTH)
```json
{ "authorizationCode": "...", "clientId": "...", "clientSecret": "...", "tokenRequestUrl": "...", "redirectUrl": "...", "url": "..." }
```

### HubSpot
```json
{ "apiKey": "...", "portalId": "12345" }
```

## Relationships

- Belongs to one Client (tenant)
- Referenced by ConnectorFieldMapping (one-to-many)

## Constraints

- Unique constraint: `(client_id, name)` — no two connectors with the same name within a client

## Notes

- Config is stored as AES-encrypted JSON. The encryption key is an environment variable.
- API responses NEVER return raw credentials. Return masked summaries only.
- This entity is tenant-scoped — all queries must filter by `client_id`.
