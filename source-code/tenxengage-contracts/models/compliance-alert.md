# ComplianceAlert Model

Represents a compliance risk alert generated by the system or raised manually.

## ComplianceAlertResponse

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| alertType | ComplianceAlertType | yes | enum | See enums.md |
| status | ComplianceAlertStatus | yes | enum | See enums.md |
| riskLevel | ComplianceRiskLevel | yes | enum | See enums.md |
| message | string | yes | max 1000 | Human-readable alert description |
| entityId | UUID | yes | — | ID of the related entity (partner, incentive, user, etc.) |
| entityType | string | yes | max 50 | Type of the related entity (e.g. "PartnerCompany", "Incentive", "User") |
| resolvedByUserId | UUID | no | foreign key, nullable | References User who resolved the alert |
| resolutionNotes | string | no | max 2000, nullable | Notes explaining the resolution |
| createdAt | datetime | yes | ISO 8601 | When the alert was generated |
| resolvedAt | datetime | no | ISO 8601, nullable | When the alert was resolved or dismissed |

## ResolveAlertRequest

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| status | ComplianceAlertStatus | yes | enum, restricted to RESOLVED or DISMISSED | Target resolution status |
| notes | string | yes | max 2000 | Explanation for the resolution |

## Business Rules

- Alerts are generated automatically by the compliance engine based on configured thresholds
- VALUE_CAP_APPROACHING: triggered when a recipient reaches the warning threshold (configurable, default 80%)
- VALUE_CAP_EXCEEDED: triggered when a reward would exceed the annual cap
- GOVERNMENT_DEAL_FLAGGED: triggered when a deal involves a government segment
- DISPROPORTIONATE_REWARD: triggered when a single reward is disproportionately large
- CONCENTRATION_ALERT: triggered when a single partner receives a disproportionate share of rewards
- KYC_EXPIRED: triggered when a partner's KYC approval expires
- Only CLIENT_ADMIN can resolve or dismiss alerts
