# WhistleblowerReport Model

Represents an anonymous whistleblower report submitted through the public reporting channel.

## WhistleblowerReportResponse

Full report visible to TENX_ADMIN only.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| trackingNumber | string | yes | unique | Anonymous tracking number for status checks |
| reportType | WhistleblowerReportType | yes | enum | See enums.md |
| status | WhistleblowerStatus | yes | enum | See enums.md |
| subject | string | yes | max 255 | Brief subject line |
| description | string | yes | max 10000 | Full report description |
| relatedIncentiveId | UUID | no | foreign key, nullable | Optional reference to an incentive program |
| relatedPartnerCompanyId | UUID | no | foreign key, nullable | Optional reference to a partner company |
| resolutionSummary | string | no | max 5000, nullable | Summary of how the report was resolved |
| submittedAt | datetime | yes | ISO 8601 | When the report was submitted |
| acknowledgedAt | datetime | no | ISO 8601, nullable | When the report was acknowledged |
| resolvedAt | datetime | no | ISO 8601, nullable | When the report was resolved |

## WhistleblowerStatusResponse

Limited public-facing status (no identifying details exposed).

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| trackingNumber | string | yes | — | The tracking number used to look up status |
| status | WhistleblowerStatus | yes | enum | See enums.md |
| submittedAt | datetime | yes | ISO 8601 | When the report was submitted |
| lastUpdatedAt | datetime | yes | ISO 8601 | When the status was last changed |

## Business Rules

- Reports are fully anonymous — no user authentication or IP logging
- Tracking number is generated server-side and returned to the submitter
- Status transitions: NEW -> ACKNOWLEDGED -> UNDER_INVESTIGATION -> RESOLVED | DISMISSED
- EU Whistleblower Directive requires acknowledgment within 7 days
- Resolution or substantive feedback must be provided within 3 months
