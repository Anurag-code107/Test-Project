# BuilderConfig Model

Configurable incentive builder layout. Controls which sections and fields appear in the incentive creation wizard, per incentive type.

## Entity: BuilderSectionConfig

| Field         | Type     | Required | Constraints   | Notes                                             |
| ------------- | -------- | -------- | ------------- | ------------------------------------------------- |
| id            | UUID     | yes      | primary key   | Generated by database                             |
| clientId      | UUID     | yes      | foreign key   | References Client (tenant)                        |
| incentiveType | string   | yes      | max 20        | IncentiveType this section belongs to             |
| sectionKey    | string   | yes      | max 50        | Machine key (e.g. "basics", "audience", "budget") |
| displayName   | string   | yes      | max 255       | Section heading                                   |
| subtitle      | string   | no       | max 500       | Section subtitle/description                      |
| sortOrder     | integer  | yes      | default 0     | Display ordering                                  |
| isLocked      | boolean  | yes      | default false | If true, section cannot be removed                |
| isVisible     | boolean  | yes      | default true  | If false, section is hidden                       |
| createdAt     | datetime | yes      | —             | ISO 8601                                          |
| updatedAt     | datetime | yes      | —             | ISO 8601                                          |

## Entity: BuilderFieldConfig

| Field               | Type     | Required | Constraints   | Notes                                                  |
| ------------------- | -------- | -------- | ------------- | ------------------------------------------------------ |
| id                  | UUID     | yes      | primary key   | Generated by database                                  |
| sectionId           | UUID     | yes      | foreign key   | References BuilderSectionConfig                        |
| fieldKey            | string   | yes      | max 100       | Machine key (e.g. "name", "description")               |
| displayName         | string   | yes      | max 255       | Field label                                            |
| fieldType           | string   | yes      | max 30        | BuilderFieldType enum value                            |
| helperText          | string   | no       | max 500       | Help text shown below the field                        |
| isMandatory         | boolean  | yes      | default false | Whether field is required                              |
| isSystem            | boolean  | yes      | default false | System fields cannot be removed                        |
| isEligibility       | boolean  | yes      | default false | Whether field is an eligibility criterion              |
| valueSource         | string   | no       | max 50        | ValueSource enum — where dropdown options come from    |
| valueSourceConfig   | jsonb    | no       | —             | Configuration for the value source (e.g. dataObjectId) |
| supportsExcelUpload | boolean  | yes      | default false | Whether values can be imported from Excel              |
| sortOrder           | integer  | yes      | default 0     | Display ordering within section                        |
| createdAt           | datetime | yes      | —             | ISO 8601                                               |
| updatedAt           | datetime | yes      | —             | ISO 8601                                               |

## Relationships

- BuilderSectionConfig belongs to Client, has many BuilderFieldConfig (cascade ALL)
- BuilderFieldConfig belongs to BuilderSectionConfig, optionally references DataObjectField

## Multi-Tenancy

- Tenant-scoped via `client_id` on BuilderSectionConfig
