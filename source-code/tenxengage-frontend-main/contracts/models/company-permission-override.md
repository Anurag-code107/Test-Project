# CompanyPermissionOverride Model

Per-partner-company permission overrides (layer 4 of the permission hierarchy). Allows granting or revoking specific permissions for all users within a partner company.

| Field            | Type     | Required | Constraints  | Notes                              |
| ---------------- | -------- | -------- | ------------ | ---------------------------------- |
| id               | UUID     | yes      | primary key  | Generated by database              |
| clientId         | UUID     | yes      | foreign key  | References Client (tenant)         |
| partnerCompanyId | UUID     | yes      | foreign key  | References PartnerCompany          |
| permissionKey    | string   | yes      | max 100      | Permission identifier              |
| granted          | boolean  | yes      | default true | Whether this permission is granted |
| createdAt        | datetime | yes      | —            | ISO 8601                           |
| updatedAt        | datetime | yes      | —            | ISO 8601                           |

## Notes

- Company overrides apply to all users within the partner company
- Individual users can be further restricted/granted via UserPermissionOverride
- Managed by users with `action.permissions.manage` permission
