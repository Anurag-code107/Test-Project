# RewardBalance Model

Tracks the accumulated reward balance for a user in a specific currency.

| Field      | Type     | Required | Constraints | Notes                                       |
| ---------- | -------- | -------- | ----------- | ------------------------------------------- |
| id         | UUID     | yes      | primary key | Generated by database                       |
| clientId   | UUID     | yes      | foreign key | References Client (tenant)                  |
| userId     | UUID     | yes      | foreign key | References User                             |
| currencyId | string   | yes      | max 50      | Currency identifier (e.g. "cash", "points") |
| balance    | decimal  | yes      | default 0   | Current accumulated balance                 |
| createdAt  | datetime | yes      | —           | ISO 8601                                    |
| updatedAt  | datetime | yes      | —           | ISO 8601                                    |

## Multi-Tenancy

- Tenant-scoped via `client_id`

## Notes

- Balances are updated atomically when claims are processed or reversed
- Each user has one balance record per currency
- TenX Engage only calculates and tracks balances; actual payouts are handled externally (XTRM for cash, third-party for points)
