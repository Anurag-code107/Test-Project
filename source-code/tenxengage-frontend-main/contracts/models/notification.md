# Notification Model

Covers the notification system: types, user notifications, preferences, and settings.

## Entity: NotificationType

Global catalog of notification types.

| Field        | Type     | Required | Constraints    | Notes                                                |
| ------------ | -------- | -------- | -------------- | ---------------------------------------------------- |
| id           | UUID     | yes      | primary key    | Generated by database                                |
| key          | string   | yes      | unique, max 80 | Machine-readable key (e.g. "incentive.activated")    |
| category     | string   | yes      | max 40         | NotificationCategory value                           |
| title        | string   | yes      | max 200        | Template title                                       |
| description  | string   | no       | max 500        | Description of when this notification fires          |
| defaultRoles | string   | no       | max 200        | Comma-separated default role types that receive this |
| createdAt    | datetime | yes      | —              | ISO 8601                                             |
| updatedAt    | datetime | yes      | —              | ISO 8601                                             |

## Entity: Notification

Individual notification delivered to a user.

| Field              | Type     | Required | Constraints   | Notes                                       |
| ------------------ | -------- | -------- | ------------- | ------------------------------------------- |
| id                 | UUID     | yes      | primary key   | Generated by database                       |
| clientId           | UUID     | yes      | foreign key   | References Client (tenant)                  |
| userId             | UUID     | yes      | foreign key   | References User                             |
| notificationTypeId | UUID     | yes      | foreign key   | References NotificationType                 |
| title              | string   | yes      | max 300       | Rendered notification title                 |
| message            | string   | yes      | max 2000      | Rendered notification body                  |
| resourceType       | string   | no       | max 50        | Type of related resource (e.g. "INCENTIVE") |
| resourceId         | UUID     | no       | —             | ID of related resource for deep linking     |
| isRead             | boolean  | yes      | default false | Whether user has read it                    |
| readAt             | datetime | no       | —             | When marked as read                         |
| createdAt          | datetime | yes      | —             | ISO 8601                                    |
| updatedAt          | datetime | yes      | —             | ISO 8601                                    |

## Entity: UserNotificationPreference

Per-type opt-in/opt-out for a user.

| Field              | Type     | Required | Constraints  | Notes                      |
| ------------------ | -------- | -------- | ------------ | -------------------------- |
| id                 | UUID     | yes      | primary key  | Generated by database      |
| clientId           | UUID     | yes      | foreign key  |                            |
| userId             | UUID     | yes      | foreign key  |                            |
| notificationTypeId | UUID     | yes      | foreign key  |                            |
| optedOut           | boolean  | yes      | default true | Whether user has opted out |
| createdAt          | datetime | yes      | —            | ISO 8601                   |
| updatedAt          | datetime | yes      | —            | ISO 8601                   |

**Constraint:** Unique `(clientId, userId, notificationTypeId)`

## Entity: UserNotificationSetting

Global notification toggle per user.

| Field                | Type     | Required | Constraints  | Notes                               |
| -------------------- | -------- | -------- | ------------ | ----------------------------------- |
| id                   | UUID     | yes      | primary key  | Generated by database               |
| clientId             | UUID     | yes      | foreign key  |                                     |
| userId               | UUID     | yes      | foreign key  |                                     |
| notificationsEnabled | boolean  | yes      | default true | Master toggle for all notifications |
| createdAt            | datetime | yes      | —            | ISO 8601                            |
| updatedAt            | datetime | yes      | —            | ISO 8601                            |

**Constraint:** Unique `(clientId, userId)`

## Multi-Tenancy

- NotificationType is global (not tenant-scoped)
- Notification, UserNotificationPreference, and UserNotificationSetting are tenant-scoped

## Notes

- Notifications are retained for a configurable number of days (see Client.notificationRetentionDays)
- Notifications are delivered via Kafka events internally
