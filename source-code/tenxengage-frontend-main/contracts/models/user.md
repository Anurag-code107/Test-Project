# User Model

Represents an authenticated user in the system.

| Field                 | Type       | Required | Constraints     | Notes                                                   |
| --------------------- | ---------- | -------- | --------------- | ------------------------------------------------------- |
| id                    | UUID       | yes      | primary key     | Generated by database                                   |
| email                 | string     | yes      | unique, max 255 | Used for login                                          |
| firstName             | string     | yes      | max 100         |                                                         |
| lastName              | string     | yes      | max 100         |                                                         |
| phone                 | string     | no       | max 20          |                                                         |
| avatar                | string     | no       | URL, max 500    | Profile photo URL                                       |
| passwordHash          | string     | yes      | —               | BCrypt hash, never exposed in API responses             |
| status                | UserStatus | yes      | enum            | See enums.md                                            |
| externalUserId        | string     | no       | max 100         | ID from external system (e.g., CRM)                     |
| organizationId        | UUID       | no       | —               | Legacy field                                            |
| clientId              | UUID       | no       | foreign key     | References Client (tenant). Null for TENX_ADMIN users   |
| partnerCompanyId      | UUID       | no       | foreign key     | References PartnerCompany. Set for partner-scoped users |
| clientRoleId          | UUID       | no       | foreign key     | References ClientRole. Determines user's permissions    |
| metadata              | jsonb      | no       | default {}      | Flexible key-value metadata                             |
| onboardingCompletedAt | datetime   | no       | —               | When the user completed onboarding                      |
| countryCode           | string     | no       | max 10          | ISO country code                                        |
| createdAt             | datetime   | yes      | —               | ISO 8601, set on creation                               |
| updatedAt             | datetime   | yes      | —               | ISO 8601, updated on modification                       |

## Relationships

- Belongs to one ClientRole (many-to-one via `client_role_id`)
- Belongs to one Client (tenant, optional — null for TENX_ADMIN)
- Belongs to one PartnerCompany (optional — set for partner-scoped users)

## Multi-Tenancy

- Tenant-scoped via `client_id` with Hibernate `@Filter`

## API Response Fields

When returned in API responses, include:

- All fields EXCEPT `passwordHash`
- `clientRoleName` — resolved from ClientRole
- `clientName` — resolved from Client (null for TENX_ADMIN)
- `partnerCompanyName` — resolved from PartnerCompany (if applicable)
- `permissions` — effective permission set for the user
