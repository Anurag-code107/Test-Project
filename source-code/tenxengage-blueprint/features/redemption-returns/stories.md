## Parallelism Notes

- **US-03 and US-04** can run in parallel once US-02 BE is done — they touch disjoint files (`ReturnVendorService`/`ReturnWebhookController` vs `ResolveTimedOutDialog`/resolve endpoint).
- **US-02 FE** can start as soon as US-01 BE is done — `ReturnDetailSheet` (defined in US-01 FE) must exist before US-02 extends it with admin-action buttons.
- **US-04 FE** depends on US-02 FE being done — `ReturnsApprovalTab` and `ReturnDetailSheet` must exist before adding the Resolve action.
- **Foundation F1–F5** are strictly sequential. F0 (contract generation) is a prerequisite outside the BE task chain.
