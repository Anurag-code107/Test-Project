# Primary-pass spec template

The primary-pass spec is generated by combining the main scaffold (below) with
per-route `test.describe` blocks and per-assertion sub-templates. Step 5's
generator code iterates `ROUTE_MANIFEST` and `INTERACTION_INVENTORY` to emit
one describe block per route and one inner test per assertion / UI state /
permission row.

## Main scaffold

```typescript
import { test, expect, type Page } from "@playwright/test";

// QA-Explore primary pass — {{SLUG}}
// Generated by /qa-explore on {{TIMESTAMP}}. DO NOT EDIT MANUALLY.

const BE_URL = "{{BE_URL}}";
const FE_URL = "{{FE_URL}}";
const WORLD_IDS = {{WORLD_IDS_JSON}};

const NOISE_PATTERNS = [
  /\[HMR\]/,
  /Fast Refresh/,
  /Download the React DevTools/,
  /React.StrictMode/,
  /Warning: ReactDOM.render/,
  /webpack-dev-server/,
  /vite.*connected/i,
  /\[vite\]/i,
];

function isNoise(text: string): boolean {
  return NOISE_PATTERNS.some((p) => p.test(text));
}

function isFlagged(text: string): boolean {
  return (
    !isNoise(text) &&
    (/Error:/i.test(text) ||
      /Uncaught/i.test(text) ||
      /TypeError/i.test(text) ||
      /ReferenceError/i.test(text) ||
      /Failed to fetch/i.test(text) ||
      /[45]\d{2}/.test(text))
  );
}

async function attachListeners(page: Page): Promise<{ consoleErrors: string[]; networkErrors: string[] }> {
  const consoleErrors: string[] = [];
  const networkErrors: string[] = [];
  page.on("console", (msg) => {
    if (isFlagged(msg.text())) consoleErrors.push(`[${msg.type()}] ${msg.text()}`);
  });
  page.on("response", (resp) => {
    if (resp.status() >= 400 && !resp.url().includes("/auth/")) {
      networkErrors.push(`${resp.status()} ${resp.url()}`);
    }
  });
  return { consoleErrors, networkErrors };
}
```

## Per-route describe block

For each route in `{{ROUTE_MANIFEST_JSON}}`, generate a `test.describe` block:

```typescript
test.describe("{{ROUTE}}", () => {
  // Resolve the route with actual IDs from WORLD_IDS
  // e.g., /assessments/:id/edit → /assessments/${WORLD_IDS.assessmentDraftId}/edit
  const resolvedRoute = "{{RESOLVED_ROUTE}}";

  test("baseline: page loads without blank screen or console errors", async ({ page }) => {
    const { consoleErrors, networkErrors } = await attachListeners(page);
    await page.goto(`${FE_URL}${resolvedRoute}`);
    await page.waitForLoadState("networkidle");
    // No blank page
    const bodyText = await page.locator("body").textContent();
    expect(bodyText?.trim().length, "Page body is empty (blank page)").toBeGreaterThan(10);
    // No "Cannot GET" (unregistered route)
    expect(bodyText).not.toContain("Cannot GET");
    // No unhandled console errors
    expect(consoleErrors, `Console errors: ${consoleErrors.join(" | ")}`).toHaveLength(0);
  });

  // One test per AC item from INTERACTION_INVENTORY[route].assertions:
  // {{GENERATED_AC_TESTS}}

  // UI state tests from INTERACTION_INVENTORY[route].uiStates:
  // {{GENERATED_UI_STATE_TESTS}}

  // DOM inventory: exercise every visible interactive element once
  test("dom-inventory: all interactive elements respond without crash", async ({ page }) => {
    const { consoleErrors } = await attachListeners(page);
    await page.goto(`${FE_URL}${resolvedRoute}`);
    await page.waitForLoadState("networkidle");

    const interactives = page.locator("button:visible, a:visible, [role='button']:visible");
    const count = await interactives.count();
    for (let i = 0; i < count; i++) {
      const el = interactives.nth(i);
      const text = (await el.textContent())?.trim() ?? `element-${i}`;
      // Skip navigation links that would leave the route manifest
      const href = await el.getAttribute("href");
      if (href && !href.startsWith("/") && !href.startsWith(FE_URL)) continue;

      await el.click({ force: false, timeout: 2000 }).catch(() => {});
      await page.waitForTimeout(300);

      // No blank page after click
      const bodyText = await page.locator("body").textContent();
      expect(bodyText?.trim().length, `Blank page after clicking "${text}"`).toBeGreaterThan(10);
      expect(consoleErrors, `Console error after clicking "${text}": ${consoleErrors.slice(-1)}`).toHaveLength(0);

      // Navigate back to the route if we left it
      if (!page.url().includes(resolvedRoute.replace(/:id/g, ""))) {
        await page.goto(`${FE_URL}${resolvedRoute}`);
        await page.waitForLoadState("networkidle");
      }
    }
  });

  // Permission boundary check (if story defines a restricted role)
  // {{GENERATED_PERMISSION_TESTS}}
});
```

## AC test sub-template

For each AC item in `{{INTERACTION_INVENTORY_JSON}}[route].assertions`, generate:

```typescript
test("AC-N: {{AC_SUMMARY}}", async ({ page }) => {
  const { consoleErrors, networkErrors } = await attachListeners(page);
  await page.goto(`${FE_URL}${resolvedRoute}`);
  await page.waitForLoadState("networkidle");
  // Verify: {{AC_VISIBLE_ASSERTION}} — use exact microcopy text from selectors where applicable
  await expect(page.getByText("{{EXPECTED_TEXT}}", { exact: false })).toBeVisible();
  expect(consoleErrors, "No console errors during AC check").toHaveLength(0);
});
```

## UI state sub-template

For each entry in `uiStates`:

```typescript
test("ui-state: {{STATE_NAME}}", async ({ page }) => {
  // If empty state: navigate to the route with no pre-existing data
  // If error state: the test world does not create this entity, so it 404s naturally
  await page.goto(`${FE_URL}${resolvedRoute}`);
  await page.waitForLoadState("networkidle");
  await expect(page.getByText("{{EXPECTED_UI_STATE_TEXT}}", { exact: false })).toBeVisible();
});
```

## Permission sub-template

If `INTERACTION_INVENTORY[route].permissions` references a restricted role
(other than the current `{{ROLE}}`):

```typescript
test("permission: restricted role cannot see admin actions", async ({ page }) => {
  // Re-authenticate as the most-restricted role referenced in the story
  // (this is a separate test from --role; it always runs as the most-restricted role)
  await page.goto(`${FE_URL}/api/v1/auth/login`); // navigate to trigger auth
  // Use learner-a@acme.com credentials
  await page.evaluate(async () => {
    await fetch("/api/v1/auth/logout", { method: "POST" });
  });
  await page.goto(`${FE_URL}${resolvedRoute}`);
  await page.waitForLoadState("networkidle");
  // Verify restricted elements are absent (not just disabled)
  // {{RESTRICTED_ELEMENT_ASSERTIONS}}
});
```

## Substitutions

| Marker | Source | Format |
|---|---|---|
| `{{BE_URL}}` | step 02 | string (e.g., `http://localhost:8081`) |
| `{{FE_URL}}` | step 02 | string (e.g., `http://localhost:3000`) |
| `{{ROLE}}` | step 01 | one of `admin`, `learner`, `seller` |
| `{{SLUG}}` | step 01 | feature slug (e.g., `assessment-authoring`) |
| `{{WORLD_IDS_JSON}}` | step 04 | JSON-serialized map of entity IDs |
| `{{ROUTE_MANIFEST_JSON}}` | step 03 | JSON-serialized route list |
| `{{INTERACTION_INVENTORY_JSON}}` | step 03 | JSON-serialized interaction inventory |
| `{{TIMESTAMP}}` | step 05 (runtime) | ISO-8601 generation timestamp embedded in spec header |
| `{{ROUTE}}` | per-route loop | route path string from `ROUTE_MANIFEST` (used as `describe` title) |
| `{{RESOLVED_ROUTE}}` | per-route loop | route with `:id` segments substituted from `WORLD_IDS` |
| `{{GENERATED_AC_TESTS}}` | per-route loop | concatenated AC test blocks emitted from the AC sub-template |
| `{{GENERATED_UI_STATE_TESTS}}` | per-route loop | concatenated UI-state test blocks emitted from the UI-state sub-template |
| `{{GENERATED_PERMISSION_TESTS}}` | per-route loop | permission test block emitted from the permission sub-template (or empty) |
| `{{AC_SUMMARY}}` | per-AC loop | short human-readable AC label used in the test title |
| `{{AC_VISIBLE_ASSERTION}}` | per-AC loop | prose description of what the AC verifies (comment only) |
| `{{EXPECTED_TEXT}}` | per-AC loop | exact microcopy text the AC asserts is visible |
| `{{STATE_NAME}}` | per-UI-state loop | UI-state label (e.g., `empty`, `error`, `loading`) |
| `{{EXPECTED_UI_STATE_TEXT}}` | per-UI-state loop | microcopy text expected in that UI state |
| `{{RESTRICTED_ELEMENT_ASSERTIONS}}` | per-permission loop | generated `expect(...).not.toBeVisible()` assertions for restricted elements |
