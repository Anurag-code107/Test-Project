# Secondary-pass spec template

The secondary-pass spec is generated by combining the main scaffold (below)
with per-route `test.describe` blocks and per-deviation test bodies. Step 6's
generator iterates `ROUTE_MANIFEST` and, for each route, emits one
`test.describe` block containing the deviation tests selected from
`references/deviation-playbook.md` (10 deviation groups; list pages get the
full set, detail/edit pages skip list-only groups).

The deviation test bodies themselves live in `references/deviation-playbook.md`
(extracted in Task 4) so the spec template stays small and the playbook stays
declarative. The spec template only contains the scaffold and the per-route
wrapper into which the playbook-derived test bodies are injected via
`{{GENERATED_DEVIATION_TESTS}}`.

## Main scaffold

```typescript
import { test, expect, type Page } from "@playwright/test";

// QA-Explore secondary pass (unconstrained deviation) — {{SLUG}} as {{ROLE}}
// Generated by /qa-explore on {{TIMESTAMP}}. DO NOT EDIT MANUALLY.

const BE_URL = "{{BE_URL}}";
const FE_URL = "{{FE_URL}}";
const WORLD_IDS = {{WORLD_IDS_JSON}};

const NOISE_PATTERNS = [
  /\[HMR\]/,
  /Fast Refresh/,
  /Download the React DevTools/,
  /React.StrictMode/,
  /Warning: ReactDOM.render/,
  /webpack-dev-server/,
  /vite.*connected/i,
  /\[vite\]/i,
];

function isNoise(text: string): boolean {
  return NOISE_PATTERNS.some((p) => p.test(text));
}

function isFlagged(text: string): boolean {
  return (
    !isNoise(text) &&
    (/Error:/i.test(text) ||
      /Uncaught/i.test(text) ||
      /TypeError/i.test(text) ||
      /ReferenceError/i.test(text) ||
      /Failed to fetch/i.test(text) ||
      /[45]\d{2}/.test(text))
  );
}

async function attachListeners(page: Page): Promise<{ consoleErrors: string[]; networkErrors: string[] }> {
  const consoleErrors: string[] = [];
  const networkErrors: string[] = [];
  page.on("console", (msg) => {
    if (isFlagged(msg.text())) consoleErrors.push(`[${msg.type()}] ${msg.text()}`);
  });
  page.on("response", (resp) => {
    if (resp.status() >= 400 && !resp.url().includes("/auth/")) {
      networkErrors.push(`${resp.status()} ${resp.url()}`);
    }
  });
  return { consoleErrors, networkErrors };
}
```

## Per-route describe block

For each route in `{{ROUTE_MANIFEST_JSON}}`, generate a `test.describe` block
into which the deviation tests selected from `{{DEVIATIONS_JSON}}` are
injected. Skip routes where the primary pass already failed with a blank-page
baseline (there is nothing useful to explore there).

```typescript
test.describe("{{ROUTE}} — deviations", () => {
  // Resolve the route with actual IDs from WORLD_IDS
  // e.g., /assessments/:id/edit → /assessments/${WORLD_IDS.assessmentDraftId}/edit
  const resolvedRoute = "{{RESOLVED_ROUTE}}";

  // Deviation tests selected from references/deviation-playbook.md
  // (10 deviation groups; list-only groups omitted on detail/edit routes).
  // Each entry in {{DEVIATIONS_JSON}} is expanded via the playbook's
  // template for that group id.
  // {{GENERATED_DEVIATION_TESTS}}
});
```

## Deviation test injection

Each entry in `{{DEVIATIONS_JSON}}` is a descriptor of shape:

```json
{
  "id": "direct-nav" | "back-button" | "refresh" | "double-click"
      | "boundary-input-xss" | "boundary-input-maxlen"
      | "filter-combo" | "viewport" | "boundary-input-empty"
      | "boundary-input-string-in-numeric" | "search-plus-filter"
      | "multi-tab",
  "appliesToRouteKinds": ["list"] | ["detail", "edit"] | ["all"]
}
```

For each descriptor whose `appliesToRouteKinds` matches the current route's
kind, look up the corresponding template body in
`references/deviation-playbook.md` and emit it inside the per-route
`describe` block above. The playbook's templates use the same `page`,
`resolvedRoute`, `attachListeners`, `isFlagged`, `FE_URL`, and `BE_URL`
symbols defined by the main scaffold.

## Substitutions

| Marker | Source | Format |
|---|---|---|
| `{{BE_URL}}` | step 02 | string (e.g., `http://localhost:8081`) |
| `{{FE_URL}}` | step 02 | string (e.g., `http://localhost:3000`) |
| `{{ROLE}}` | step 01 | one of `admin`, `learner`, `seller` |
| `{{SLUG}}` | step 01 | feature slug (e.g., `assessment-authoring`) |
| `{{WORLD_IDS_JSON}}` | step 04 | JSON-serialized map of entity IDs |
| `{{ROUTE_MANIFEST_JSON}}` | step 03 | JSON-serialized route list |
| `{{DEVIATIONS_JSON}}` | step 06 | JSON array of deviation descriptors built from `references/deviation-playbook.md` (10 deviation groups) |
| `{{TIMESTAMP}}` | step 06 (runtime) | ISO-8601 generation timestamp embedded in spec header |
| `{{ROUTE}}` | per-route loop | route path string from `ROUTE_MANIFEST` (used as `describe` title) |
| `{{RESOLVED_ROUTE}}` | per-route loop | route with `:id` segments substituted from `WORLD_IDS` |
| `{{GENERATED_DEVIATION_TESTS}}` | per-route loop | concatenated deviation test blocks emitted from the playbook templates for descriptors whose `appliesToRouteKinds` matches the current route kind |
