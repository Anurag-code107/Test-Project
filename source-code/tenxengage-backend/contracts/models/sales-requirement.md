# SalesRequirement Model

A named requirement group for a sales incentive, containing eligibility rules and payout configuration.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| incentiveId | UUID | yes | foreign key | References Incentive |
| name | string | yes | max 255 | Requirement name (e.g. "Enterprise Server Sales") |
| sortOrder | integer | yes | — | Display order |
| createdAt | datetime | yes | — | Set on creation |
| updatedAt | datetime | yes | — | Updated on modification |

## Relationships

- Belongs to one Incentive
- Has many EligibilityRuleGroup (one-to-many)
- Has many PayoutConfig (one-to-many)

---

# EligibilityRuleGroup Model

A group of eligibility rules joined by AND logic. Multiple groups are joined by OR logic.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| requirementId | UUID | yes | foreign key | References SalesRequirement |
| sortOrder | integer | yes | — | Display order |

## Relationships

- Belongs to one SalesRequirement
- Has many EligibilityRule (one-to-many)

---

# EligibilityRule Model

A single eligibility rule within a rule group.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| ruleGroupId | UUID | yes | foreign key | References EligibilityRuleGroup |
| ruleType | EligibilityRuleType | yes | enum | PRODUCTS, BOOKING_AMOUNT, CUSTOMER_TYPE |
| operator | RuleOperator | no | enum | GREATER_THAN, GREATER_THAN_OR_EQUAL, BETWEEN, EQUALS, IN |
| value | string | no | max 500 | Single value or JSON array for multi-select |
| valueMax | string | no | max 255 | Upper bound for BETWEEN operator |
| selectedProducts | string[] | no | JSON | Array of product IDs (when ruleType = PRODUCTS) |
| sortOrder | integer | yes | — | Display order |

---

# PayoutConfig Model

Payout configuration for a sales requirement.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| requirementId | UUID | yes | foreign key | References SalesRequirement |
| currencyId | string | yes | max 50 | Currency identifier (e.g. "cash", "points") |
| payoutType | PayoutType | yes | enum | PERCENTAGE, FLAT |
| against | PayoutAgainst | no | enum | TOTAL_BOOKING, ELIGIBLE_PRODUCTS |
| maxPerDeal | string | no | decimal string | Maximum payout per deal |
| sortOrder | integer | yes | — | Display order |

## Relationships

- Belongs to one SalesRequirement
- Has many PayoutBand (one-to-many)

---

# PayoutBand Model

A payout band within a payout config (tiered payouts based on amount ranges).

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| payoutConfigId | UUID | yes | foreign key | References PayoutConfig |
| minAmount | string | yes | decimal string | Lower bound of range |
| maxAmount | string | yes | decimal string | Upper bound of range |
| payoutValue | string | yes | decimal string | Payout amount or percentage |
| sortOrder | integer | yes | — | Display order |
