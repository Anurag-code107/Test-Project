# ComplianceValueCap Model

Represents a per-country annual reward value cap for anti-bribery compliance.

## Entity Fields

| Field                     | Type     | Required | Constraints           | Notes                                                             |
| ------------------------- | -------- | -------- | --------------------- | ----------------------------------------------------------------- |
| id                        | UUID     | yes      | primary key           | Generated by database                                             |
| countryCode               | string   | yes      | max 10                | ISO 3166-1 alpha-2 code (e.g. "US", "DE")                         |
| annualCapAmount           | decimal  | yes      | precision 15,2        | Annual maximum reward value                                       |
| annualCapCurrency         | string   | yes      | max 10, default "USD" | Currency of the cap                                               |
| enhancedApprovalThreshold | decimal  | no       | precision 15,2        | Amount above which enhanced approval is required                  |
| clientId                  | UUID     | no       | —                     | Null for platform defaults (TENX_ADMIN), set for client overrides |
| createdAt                 | datetime | yes      | ISO 8601              | Set on creation                                                   |
| updatedAt                 | datetime | yes      | ISO 8601              | Last modification                                                 |

## Constraints

- Unique constraint: `(country_code, client_id)`

## Business Rules

- Value caps are checked in real-time when rewards are issued
- When a recipient approaches 80% of the cap, a VALUE_CAP_APPROACHING alert is generated
- When a recipient exceeds the cap, a VALUE_CAP_EXCEEDED alert is generated and the reward is blocked
- Platform defaults (clientId = null) apply when no client override exists
- Currency conversion uses the rates defined in the platform (see currency_conversions.md)
