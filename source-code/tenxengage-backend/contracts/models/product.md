# Product Model

Represents a product in the tenant's product catalog. Used for incentive eligibility rules and purchase order line items.

| Field     | Type     | Required | Constraints             | Notes                      |
| --------- | -------- | -------- | ----------------------- | -------------------------- |
| id        | UUID     | yes      | primary key             | Generated by database      |
| clientId  | UUID     | yes      | foreign key             | References Client (tenant) |
| sku       | string   | yes      | max 20                  | Product SKU                |
| name      | string   | yes      | —                       | Product display name       |
| category  | string   | no       | max 100, default "None" | Product category           |
| createdAt | datetime | yes      | —                       | ISO 8601                   |
| updatedAt | datetime | yes      | —                       | ISO 8601                   |

## Multi-Tenancy

- Tenant-scoped via `client_id`

## Notes

- Products can be created individually or bulk-uploaded via CSV
- Product categories are used for eligibility rule matching (EligibilityRuleType.PRODUCTS)
- Referenced by PurchaseOrderLine and incentive sales rules
