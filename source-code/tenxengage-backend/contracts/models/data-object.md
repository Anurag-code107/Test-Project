# DataObject Model

Represents a configurable data object (e.g. Sales Data, Partner Data) defined by a Client Admin. Each object contains dynamic fields that can be mapped to external connector sources and used in the incentive rules engine.

## DataObject

| Field       | Type     | Required | Constraints   | Notes                             |
| ----------- | -------- | -------- | ------------- | --------------------------------- |
| id          | UUID     | yes      | primary key   | Generated by database             |
| clientId    | UUID     | yes      | foreign key   | References Client (tenant)        |
| name        | string   | yes      | max 255       | Display name (e.g. "Sales Data")  |
| description | string   | no       | max 1000      | Description of this data object   |
| isDefault   | boolean  | yes      | default false | Default objects cannot be deleted |
| sortOrder   | integer  | yes      | default 0     | Display ordering                  |
| createdAt   | datetime | yes      | —             | ISO 8601, set on creation         |
| updatedAt   | datetime | yes      | —             | ISO 8601, updated on modification |

## DataObjectField

| Field            | Type          | Required | Constraints   | Notes                                                                       |
| ---------------- | ------------- | -------- | ------------- | --------------------------------------------------------------------------- |
| id               | UUID          | yes      | primary key   | Generated by database                                                       |
| dataObjectId     | UUID          | yes      | foreign key   | References DataObject                                                       |
| name             | string        | yes      | max 255       | Field name (e.g. "Product SKU")                                             |
| description      | string        | no       | max 1000      | Field description                                                           |
| dataType         | FieldDataType | yes      | enum          | See enums.md                                                                |
| ruleLabel        | string        | no       | max 255       | Natural-language label for the incentive rules engine (e.g. "has products") |
| excludeFromRules | boolean       | yes      | default false | If true, this field is not available in the rules engine                    |
| sampleValues     | string[]      | no       | JSON array    | Example values for rules engine dropdowns                                   |
| mandatory        | boolean       | yes      | default false | If true, this field is required during data upload                          |
| ruleWidget       | string        | no       | max 30        | UI widget hint for rules engine (e.g. "multiselect", "range")               |
| sortOrder        | integer       | yes      | default 0     | Display ordering within the data object                                     |
| visibleOnProfile | boolean       | yes      | default false | If true, this field appears on user profile pages                           |
| editableByUser   | boolean       | yes      | default false | If true, the user can edit this field on their profile                      |
| createdAt        | datetime      | yes      | —             | ISO 8601, set on creation                                                   |
| updatedAt        | datetime      | yes      | —             | ISO 8601, updated on modification                                           |

## ConnectorFieldMapping

| Field        | Type     | Required | Constraints | Notes                                                               |
| ------------ | -------- | -------- | ----------- | ------------------------------------------------------------------- |
| id           | UUID     | yes      | primary key | Generated by database                                               |
| dataObjectId | UUID     | yes      | foreign key | References DataObject (parent mapping)                              |
| connectorId  | UUID     | yes      | foreign key | References Connector                                                |
| fieldId      | UUID     | yes      | foreign key | References DataObjectField                                          |
| sourceTable  | string   | yes      | max 255     | Table/object name in the external source (follows connector syntax) |
| sourceField  | string   | yes      | max 255     | Field/column name in the external source                            |
| createdAt    | datetime | yes      | —           | ISO 8601, set on creation                                           |
| updatedAt    | datetime | yes      | —           | ISO 8601, updated on modification                                   |

## Relationships

- DataObject belongs to one Client (tenant)
- DataObject has many DataObjectField (one-to-many, cascade delete)
- DataObject has many ConnectorFieldMapping (one-to-many, cascade delete)
- ConnectorFieldMapping references one Connector and one DataObjectField

## Constraints

- Unique constraint on DataObject: `(client_id, name)`
- Unique constraint on DataObjectField: `(data_object_id, name)`
- Unique constraint on ConnectorFieldMapping: `(data_object_id, field_id)` — each field maps to one source per data object mapping

## Default Data Objects

Two default objects are seeded per client:

### Sales Data

Fields: PO# (text), Booking Date (date), Partner Name (text, excludeFromRules), Partner ID (text, excludeFromRules), Customer Name (text), Customer ID (text), Customer Segment (list), Product SKU (text), Quantity (number), Net Bookings (currency)

### Partner Data

Fields: Partner Name (text), Partner ID (text), Employee First Name (text), Employee Last Name (text), Employee ID (text), Employee Email (text), Admin Status (boolean), Employment Status (list)

## Notes

- This entity is tenant-scoped — all queries must filter by `client_id`.
- Default objects (`isDefault = true`) cannot be deleted but their fields can be edited.
- The `ruleLabel` provides natural English phrasing for the incentive rules engine sentence builder (e.g. "has products" instead of "Product SKU").
- `sampleValues` can be used to populate dropdown options in the rules engine for list/text fields.
