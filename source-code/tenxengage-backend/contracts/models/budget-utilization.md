# BudgetUtilization Model

Tracks how much of an incentive's budget has been utilized, broken down by currency and optionally by location.

## Entity: BudgetUtilization

| Field           | Type     | Required | Constraints | Notes                                      |
| --------------- | -------- | -------- | ----------- | ------------------------------------------ |
| id              | UUID     | yes      | primary key | Generated by database                      |
| incentiveId     | UUID     | yes      | foreign key | References Incentive                       |
| currencyId      | string   | yes      | max 50      | Currency identifier                        |
| locationValueId | UUID     | no       | foreign key | References LocationValue (null for global) |
| utilized        | decimal  | yes      | default 0   | Amount utilized so far                     |
| createdAt       | datetime | yes      | —           | ISO 8601                                   |
| updatedAt       | datetime | yes      | —           | ISO 8601                                   |

## Entity: LocationBudgetAllocation

Per-location budget allocation within a PER_LOCATION budget.

| Field           | Type     | Required | Constraints    | Notes                      |
| --------------- | -------- | -------- | -------------- | -------------------------- |
| id              | UUID     | yes      | primary key    | Generated by database      |
| budgetId        | UUID     | yes      | foreign key    | References IncentiveBudget |
| locationValueId | UUID     | yes      | foreign key    | References LocationValue   |
| amount          | decimal  | yes      | precision 15,2 | Allocated budget amount    |
| createdAt       | datetime | yes      | —              | ISO 8601                   |
| updatedAt       | datetime | yes      | —              | ISO 8601                   |

**Constraint:** Unique `(budgetId, locationValueId)`

## Notes

- BudgetUtilization is updated atomically during claim processing
- When budgetMode = PER_LOCATION, utilization is tracked per location
- Budget capping checks utilization against the relevant allocation before awarding rewards
