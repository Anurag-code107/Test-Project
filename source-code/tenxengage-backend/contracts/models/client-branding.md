# ClientBranding Model

Per-tenant branding configuration — HSL color tokens and font families applied to the tenxengage-frontend UI via CSS custom properties. One row per tenant.

| Field             | Type     | Required | Constraints                 | Notes                                                  |
| ----------------- | -------- | -------- | --------------------------- | ------------------------------------------------------ |
| id                | UUID     | yes      | primary key                 | Generated by database                                  |
| clientId          | UUID     | yes      | foreign key, unique         | References Client (tenant). One branding row per tenant |
| primary           | string   | yes      | max 32, HSL "H S% L%" form  | Main brand color for buttons, links, accents          |
| primaryLight      | string   | yes      | max 32, HSL "H S% L%" form  | Lighter variant for gradients                          |
| secondary         | string   | yes      | max 32, HSL "H S% L%" form  | Supporting backgrounds                                 |
| accent            | string   | yes      | max 32, HSL "H S% L%" form  | Emphasis for special elements                          |
| success           | string   | yes      | max 32, HSL "H S% L%" form  | Positive states                                        |
| warning           | string   | yes      | max 32, HSL "H S% L%" form  | Cautionary messages                                    |
| destructive       | string   | yes      | max 32, HSL "H S% L%" form  | Errors and destructive actions                         |
| background        | string   | yes      | max 32, HSL "H S% L%" form  | Main page background                                   |
| foreground        | string   | yes      | max 32, HSL "H S% L%" form  | Main text color                                        |
| muted             | string   | yes      | max 32, HSL "H S% L%" form  | Subdued backgrounds                                    |
| mutedForeground   | string   | yes      | max 32, HSL "H S% L%" form  | Subdued text color                                     |
| card              | string   | yes      | max 32, HSL "H S% L%" form  | Card backgrounds                                       |
| cardForeground    | string   | yes      | max 32, HSL "H S% L%" form  | Card text color                                        |
| border            | string   | yes      | max 32, HSL "H S% L%" form  | Borders and dividers                                   |
| headingFont       | string   | yes      | max 64                      | Font family for headings (e.g. "Inter")                |
| bodyFont          | string   | yes      | max 64                      | Font family for body text                              |
| logoUrl           | string?  | no       | max 512, nullable           | Public URL of the tenant's custom logo. `null` = use the default tenXengage logo |
| createdAt         | datetime | yes      | —                           | ISO 8601                                               |
| updatedAt         | datetime | yes      | —                           | ISO 8601                                               |

## Multi-Tenancy

- Tenant-scoped via `client_id`
- Unique constraint on `client_id` — exactly one branding row per tenant

## Notes

- All HSL values are stored as `"H S% L%"` strings (space-separated, no `hsl()` wrapper). The frontend composes them into `hsl(<value>)` when applying.
- Absence of a row means "use default theme" — the backend returns default values for a tenant without a saved row so the frontend never needs to handle 404.
- The `PUT` endpoint upserts: if no row exists for the tenant, one is created.
- The `PUT` body does NOT include `logoUrl`. Logo is managed exclusively via `POST /api/v1/branding/logo` (multipart upload) and `DELETE /api/v1/branding/logo` (clear). Colors/fonts and the logo are separate concerns to avoid accidental clears.
- Logo files are stored via the backend's `FileStorageService` (S3 / GCP / Local depending on profile). Accepted MIME types are `image/png`, `image/jpeg`, `image/svg+xml`, `image/webp`; maximum size 2 MB.
- Dark-mode branding is not yet supported. Current tokens apply to light mode only.
