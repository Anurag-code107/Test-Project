# LegalPolicy Model

Represents a legal policy that users must accept (privacy notice, terms of service, anti-bribery policy).

## LegalPolicyResponse

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| policyType | PolicyType | yes | enum | See enums.md |
| title | string | yes | max 255 | Display title of the policy |
| version | string | yes | max 50 | Semantic version (e.g. "1.0", "2.1") |
| contentUrl | string | yes | format: URI, max 500 | URL to the policy document |
| required | boolean | yes | — | Whether acceptance is mandatory for onboarding |
| effectiveDate | date | yes | ISO 8601 date | Date when this policy version takes effect |

## Relationships

- Accepted by many Users (many-to-many via `user_policy_acceptances` join table)
- Belongs to one Client (tenant-scoped, or null for platform-wide policies)
