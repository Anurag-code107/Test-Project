# ActivityCategory Model

Represents a configurable activity category for activity-based incentives. Categories are defined per-tenant.

| Field       | Type     | Required | Constraints | Notes                      |
| ----------- | -------- | -------- | ----------- | -------------------------- |
| id          | UUID     | yes      | primary key | Generated by database      |
| clientId    | UUID     | yes      | foreign key | References Client (tenant) |
| name        | string   | yes      | max 100     | Category name              |
| description | string   | no       | max 500     | Category description       |
| sortOrder   | integer  | yes      | default 0   | Display ordering           |
| createdAt   | datetime | yes      | —           | ISO 8601                   |
| updatedAt   | datetime | yes      | —           | ISO 8601                   |

## Multi-Tenancy

- Tenant-scoped via `client_id`

## Notes

- Categories are used as the `categoryId` on ActivityDefinition
- Also available as a ValueSource for dynamic builder fields
- Managed by users with `action.builder.manage` permission
