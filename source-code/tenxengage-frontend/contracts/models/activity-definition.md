# ActivityDefinition Model

Defines an activity that must be completed as part of an activity incentive.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| incentiveId | UUID | yes | foreign key | References Incentive |
| name | string | yes | max 255 | Activity name |
| description | string | no | max 2000 | Activity description |
| categoryId | string | yes | max 100 | Activity category identifier |
| sortOrder | integer | yes | — | Display order |
| createdAt | datetime | yes | — | Set on creation |
| updatedAt | datetime | yes | — | Updated on modification |

## Relationships

- Belongs to one Incentive
- Has many ActivityDocumentRequirement (one-to-many)

---

# ActivityDocumentRequirement Model

A document that must be uploaded to verify activity completion.

| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| id | UUID | yes | primary key | Generated by database |
| activityDefinitionId | UUID | yes | foreign key | References ActivityDefinition |
| name | string | yes | max 255 | Document name (e.g. "Site Visit Photo") |
| description | string | no | max 1000 | Description of what to upload |
| required | boolean | yes | default true | Whether upload is mandatory |
| sortOrder | integer | yes | — | Display order |
