# Recommendation Model

AI-powered recommendation system for suggesting training courses and incentive programs to users.

## Entity: RecommendationConfig

Per-tenant configuration for the recommendation engine.

| Field                       | Type     | Required | Constraints  | Notes                                  |
| --------------------------- | -------- | -------- | ------------ | -------------------------------------- |
| id                          | UUID     | yes      | primary key  | Generated by database                  |
| clientId                    | UUID     | yes      | foreign key  | References Client (tenant)             |
| trainingEnabled             | boolean  | yes      | default true | Enable training recommendations        |
| incentiveEnabled            | boolean  | yes      | default true | Enable incentive recommendations       |
| maxTrainingRecommendations  | integer  | yes      | default 5    | Max training recs shown                |
| maxIncentiveRecommendations | integer  | yes      | default 5    | Max incentive recs shown               |
| rewardCurrencyId            | string   | no       | max 50       | Currency for completion rewards        |
| trainingCompletionReward    | decimal  | no       | default 0    | Reward for completing a training rec   |
| incentiveCompletionReward   | decimal  | no       | default 0    | Reward for completing an incentive rec |
| createdAt                   | datetime | yes      | —            | ISO 8601                               |
| updatedAt                   | datetime | yes      | —            | ISO 8601                               |

## Entity: RecommendationScore

Computed recommendation relevance score for a user.

| Field              | Type     | Required | Constraints              | Notes                                     |
| ------------------ | -------- | -------- | ------------------------ | ----------------------------------------- |
| id                 | UUID     | yes      | primary key              | Generated by database                     |
| clientId           | UUID     | yes      | foreign key              |                                           |
| userId             | UUID     | yes      | foreign key              |                                           |
| recommendationType | string   | yes      | max 20                   | RecommendationType: TRAINING or INCENTIVE |
| targetId           | UUID     | yes      | —                        | ID of the recommended course or incentive |
| score              | decimal  | yes      | precision 8,4, default 0 | Relevance score                           |
| scoreBreakdown     | jsonb    | no       | default {}               | How the score was computed                |
| rank               | integer  | yes      | default 0                | Display rank                              |
| reasonCode         | string   | no       | max 50                   | Why this was recommended                  |
| computedAt         | datetime | yes      | —                        | When the score was last computed          |
| createdAt          | datetime | yes      | —                        | ISO 8601                                  |
| updatedAt          | datetime | yes      | —                        | ISO 8601                                  |

## Entity: RecommendationInteraction

Tracks user interactions with recommendations.

| Field              | Type     | Required | Constraints | Notes                           |
| ------------------ | -------- | -------- | ----------- | ------------------------------- |
| id                 | UUID     | yes      | primary key | Generated by database           |
| clientId           | UUID     | yes      | foreign key |                                 |
| userId             | UUID     | yes      | foreign key |                                 |
| recommendationType | string   | yes      | max 20      | TRAINING or INCENTIVE           |
| targetId           | UUID     | yes      | —           | ID of the recommended item      |
| interactionType    | string   | yes      | max 20      | VIEWED, DISMISSED, or COMPLETED |
| createdAt          | datetime | yes      | —           | ISO 8601                        |
| updatedAt          | datetime | yes      | —           | ISO 8601                        |

## Multi-Tenancy

- All entities are tenant-scoped via `client_id`
