# ClientPermissionGrant Model

Tenant-level permission grants. Controls which permissions are available within a client (layer 2 of the permission hierarchy).

| Field         | Type     | Required | Constraints  | Notes                                             |
| ------------- | -------- | -------- | ------------ | ------------------------------------------------- |
| id            | UUID     | yes      | primary key  | Generated by database                             |
| clientId      | UUID     | yes      | foreign key  | References Client                                 |
| permissionKey | string   | yes      | max 100      | Permission identifier                             |
| granted       | boolean  | yes      | default true | Whether this permission is enabled for the tenant |
| createdAt     | datetime | yes      | —            | ISO 8601                                          |
| updatedAt     | datetime | yes      | —            | ISO 8601                                          |

## Notes

- Managed by TENX_ADMIN via the tenant-permissions endpoint
- If a permission is not granted at the tenant level, it cannot be granted at any lower layer (role, company, user)
- By default, all permissions are implicitly granted unless explicitly revoked
